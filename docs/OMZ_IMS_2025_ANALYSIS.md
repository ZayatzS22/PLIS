# ОМЗ — внутренние наработки по IMS, 2025

Источник: `Презентация IMS.pdf`, 15 страниц.

Документ подготовлен в АО «Омутнинский металлургический завод», САиС, 2025 год. Это не документация Bosch, а наши собственные ранние исследования принципа IMS и попытка сформировать физическую и алгоритмическую модель будущего датчика.

Этот файл фиксирует содержание презентации, а также отдельно отмечает, как оно связано с текущим стендом SP605 и какие места требуют перепроверки.

---

# 1. Базовая идея внутреннего проекта

Система рассматривается как индуктивный датчик положения, состоящий из:

```text
катушек
+
металлической периодической структуры
```

В исходном примере используется перфорированная металлическая лента.

Для нашего изделия предлагается заменить физическую перфорацию на лазерную гравировку аналогичной геометрии непосредственно на направляющей/измерительной поверхности.

---

# 2. Геометрия шкалы в презентации

Внутренний документ указывает для исходной металлической ленты:

```text
толщина около 0,5 мм
период структуры = 1 мм
заявленная точность изготовления = 0,5 мкм
```

На следующей странице показана лазерная гравировка на рельсе как предполагаемая замена перфорированной ленты.

Это один из самых важных параметров нашей будущей системы: физическая геометрия шкалы должна быть технологически воспроизводима на рельсах нашего производства.

---

# 3. Аналоговый тракт в исходной конструкции

Сигнал с катушек передается через гибкий шлейф.

На шлейфе установлены предварительные усилители, расположенные максимально близко к катушкам.

Причина такого размещения — снизить влияние помех на слабые аналоговые сигналы до передачи на основную печатную плату.

Цепочка по внутренней презентации:

```text
катушки
↓
предварительные усилители рядом с катушками
↓
шлейф
↓
основная печатная плата датчика
```

Для нашего проекта это означает, что вопрос аналогового front-end критичен и должен быть документирован отдельно от FPGA.

---

# 4. Плата катушек

В презентации описана гибкая многослойная печатная плата:

```text
толщина: 0,1 мм
длина: 28 мм
ширина: 5 мм
размер дорожек: 20...40 мкм
```

Плата крепится тыльной стороной к магнитонейтральному материалу.

Указано наличие трех групп обмоток:

1. первичная, или генераторная;
2. приемная группа SIN;
3. приемная группа COS.

---

# 5. Квадратурные приемные каналы SIN/COS

Согласно внутреннему документу приемные группы SIN и COS сдвинуты относительно друг друга на 90° по фазе.

Это формирует квадратурную пару сигналов.

Практическое значение квадратуры:

```text
SIN + COS
→ положение внутри периода
→ определение направления движения
```

В презентации прямо отмечено, что квадратурный сигнал позволяет не только считать периоды, но и однозначно определять направление движения.

---

# 6. Суммирование нескольких приемных катушек

Канал SIN формируется как сумма шести катушек:

```text
U_SIN = U_SIN1 + U_SIN2 + U_SIN3 + U_SIN4 + U_SIN5 + U_SIN6
```

Для COS предполагается аналогичная структура.

Всего указано 12 чередующихся измерительных катушек.

В презентации упоминается период их размещения 1,75 мм вдоль платы.

Смысл нескольких одинаковых секций — увеличить полезную амплитуду и получить более устойчивый суммарный сигнал.

Для будущего алгоритма это важно: выход A/B — уже пространственно усредненный сигнал нескольких участков шкалы, а не измерение одной точки.

---

# 7. Коэффициент трансформации

В документе вводится отношение:

```text
k = U_ген / U_SIN
```

как коэффициент трансформации между генераторной и приемной обмотками.

Точный диапазон этого коэффициента в презентации не задан, поэтому для нашего датчика его нужно измерять экспериментально в зависимости от:

- зазора;
- материала шкалы;
- глубины/геометрии лазерной структуры;
- частоты возбуждения;
- геометрии катушек;
- температуры;
- положения датчика.

---

# 8. Дифференциальная конструкция одной приемной катушки

В презентации подробно рассматривается SIN1.

Катушка имеет две симметричные половины:

```text
w1 — левая
w2 — правая
```

Они включены встречно.

Результирующий сигнал:

```text
U_SIN1 = U_левое - U_правое
```

Следовательно:

```text
если U_левое = U_правое → U_SIN1 = 0
если U_левое > U_правое → U_SIN1 > 0
если U_левое < U_правое → U_SIN1 < 0
```

Дифференциальная топология делает датчик чувствительным именно к асимметрии распределения поля относительно двух половин катушки.

---

# 9. Физический принцип — вихревые токи

Высокочастотное поле генераторной катушки возбуждает вихревые токи в проводящей металлической структуре.

Эти токи создают встречное магнитное поле и уменьшают исходное поле генераторной катушки.

Поэтому наличие металла и отсутствие металла над разными половинами приемной катушки изменяет их наведенные напряжения.

Во внутреннем документе этот принцип описан как вихретоковый/индуктивный.

Это согласуется с общим индуктивным принципом, который Bosch указывает для IMS, хотя внутреннее устройство Bosch полностью в открытой документации не раскрывается.

---

# 10. Зависимость сигнала от положения

В презентации показан один цикл относительного движения структуры и катушки.

Для канала SIN1 приводятся характерные точки:

```text
Δx = 0 мм     → U_SIN1 = 0
Δx = 0,125 мм → U_SIN1 > 0
Δx = 0,25 мм  → U_SIN1 = +Umax
Δx = 0,5 мм   → U_SIN1 = 0
Δx = 0,75 мм  → U_SIN1 = -Umax
```

На графике страницы 12 зависимость аппроксимируется синусоидой.

Внутренняя рабочая модель:

```text
U_SIN = f(Δx)
```

с периодом 1 мм.

Это предполагает:

```text
U_SIN ≈ A * sin(2πx / 1мм + φ0)
U_COS ≈ B * cos(2πx / 1мм + φ0)
```

после соответствующей аналоговой обработки.

---

# 11. Физический период в нашей внутренней модели

Презентация считает, что измерение приемными катушками имеет период перфорированной структуры:

```text
P = 1 мм
```

То есть один полный цикл SIN/COS соответствует перемещению на 1 мм.

Эта модель должна быть проверена на реальном прототипе с нашей лазерной структурой.

---

# 12. Расчет максимальной частоты полезного перемещения

В документе используется предполагаемая максимальная скорость:

```text
v = 5 м/с
```

при периоде:

```text
P = 1 мм = 0,001 м
```

Частота прохода меток:

```text
f_метки = v / P = 5 / 0,001 = 5000 Гц = 5 кГц
```

То есть при 5 м/с геометрическая структура с шагом 1 мм меняется для датчика с частотой до 5 кГц.

---

# 13. Частота возбуждения

Во внутреннем документе указано:

```text
Bosch: f_возб = 625 кГц
Arduino-макет: около 666 кГц
```

Также приводится инженерное правило, что частота возбуждения должна быть существенно выше частоты изменения положения — ориентировочно в 5–10 раз или больше.

Важно: значение 625 кГц в нашем внутреннем документе не следует автоматически считать подтвержденным официальной открытой документацией Bosch. Для нашей схемы оно является исходной проектной гипотезой/ориентиром и должно подтверждаться экспериментом и реальной аналоговой схемой.

---

# 14. Как в презентации трактуется сигнал приемной катушки

Документ рассматривает сигнал приемной катушки как высокочастотный сигнал возбуждения, амплитуда которого модулируется положением.

Упрощенно:

```text
несущая: около 625 кГц
огибающая: SIN/COS от перемещения
максимальная частота огибающей при 5 м/с: около 5 кГц
```

То есть математически ожидается не просто низкочастотная синусоида, а AM-подобный сигнал:

```text
u(t) ≈ A(x(t)) * cos(2π f_exc t + θ)
```

где `A(x)` зависит от координаты.

Затем должна быть получена низкочастотная квадратурная информация положения.

---

# 15. Требования к АЦП из внутренней презентации

На страницах 14–15 проведен расчет, исходя из предположения, что АЦП напрямую оцифровывает высокочастотный сигнал приемной катушки.

Используется критерий Найквиста:

```text
f_ADC >= 2 * f_max
```

При `f_exc = 625 кГц`:

```text
теоретический минимум: 1,25 МГц
```

Для хорошей обработки и интерполяции предложено:

```text
f_ADC ≈ 10 * 625 кГц = 6,25 МГц
```

При максимальной скорости 5 м/с и периоде 1 мм получено:

```text
f_envelope = 5 кГц
N = 6,25 МГц / 5 кГц = 1250 отсчетов на один период 1 мм
```

---

# 16. Важнейшее расхождение с выбранным AD7357

В текущем основном стенде используется AD7357.

По официальному datasheet AD7357 максимальная производительность:

```text
4,2 MSPS на канал
```

Следовательно, AD7357 физически не достигает рекомендуемых во внутренней презентации `6,25 MSPS`, если мы действительно хотим напрямую дискретизировать 625-кГц несущую с десятью отсчетами на период.

При 4,2 MSPS теоретически получится:

```text
4,2 МГц / 625 кГц ≈ 6,72 отсчета на период несущей
```

Это выше критерия Найквиста, но ниже внутреннего проектного ориентира 10 отсчетов на период.

---

# 17. Еще более важное расхождение с текущим кодом SP605

В `Main/sin_gen/sin_gen.v` сигнал `adc_clk` формируется примерно как:

```text
27 МГц / 44 ≈ 613,6 кГц SCLK
```

AD7357 требует 16 тактов SCLK на одно преобразование.

Поэтому фактическая частота получения полных пар ADC A/B при такой схеме находится лишь в диапазоне десятков тысяч преобразований в секунду, а не мегасэмплов.

Это намного ниже параметров, рассчитанных во внутренней презентации для прямой оцифровки 625-кГц несущей.

Отсюда возникает **критический архитектурный вопрос**:

> Что именно сейчас физически подается на вход AD7357 основного стенда?

Возможны два принципиально разных варианта.

### Вариант A — на ADC идет сырая 625-кГц несущая

Тогда текущая скорость чтения ADC принципиально недостаточна для модели из презентации.

### Вариант B — перед ADC уже выполнено аналоговое усиление и демодуляция

Тогда на ADC могут поступать уже медленные SIN/COS-огибающие, и высокая частота дискретизации несущей не нужна.

**Без схемы аналогового тракта нельзя определить, какой вариант реализован на реальном стенде.**

Это один из главных вопросов, который необходимо выяснить до разработки алгоритма FPGA.

---

# 18. Расхождение с открытой документацией Bosch по периоду

Внутренняя презентация рассматривает:

```text
физический период = 1 мм
период SIN/COS = 1 мм
```

Официальный каталог Bosch IMS-I 2014 при этом указывает:

```text
цена деления физической шкалы = 1000 мкм
период аналогового выходного A/B = 40 мкм
```

То есть в законченной системе Bosch физический миллиметровый шаг и электрический период внешнего сигнала не совпадают.

Это может означать:

- более сложную геометрию многокатушечного scanner;
- внутреннюю пространственную интерполяцию;
- внутреннюю электронную обработку;
- либо то, что наша презентация описывает сигнал на другом уровне тракта, до той обработки, которая формирует внешний 40-мкм интерфейс Bosch.

Для нашего изделия этот вопрос нужно решить самостоятельно, а не копировать число 40 мкм или 1 мм без измерений.

# 19. Что уже хорошо определено внутренней презентацией

Документ дает полезную основу:

1. выбран индуктивный/вихретоковый принцип;
2. предполагается лазерная периодическая структура на нашем рельсе;
3. предусмотрены генераторная и две квадратурные приемные группы;
4. SIN/COS должны быть сдвинуты на 90°;
5. приемные катушки дифференциальные;
6. предварительные усилители должны быть рядом с катушками;
7. задан исходный период структуры 1 мм;
8. рассматривается максимальная скорость 5 м/с;
9. сформулирована задача интерполяции между метками;
10. сделана первичная оценка требований к частоте возбуждения и АЦП.

# 20. Чего в презентации еще нет

Для полноценного рабочего датчика не определены:

- точная электрическая схема генератора;
- амплитуда генераторного сигнала;
- схема предварительного усилителя;
- тип синхронного детектора/демодулятора;
- фильтры;
- точные amplitudes SIN/COS;
- допустимый воздушный зазор;
- влияние перекоса/смещения головки;
- влияние температуры;
- гармонические искажения;
- алгоритм нормализации SIN/COS;
- алгоритм `atan2`/CORDIC;
- phase unwrap;
- глобальная нумерация периодов;
- реферная/absolute структура;
- калибровка по эталону;
- карта систематической ошибки вдоль рельса;
- диагностические критерии плохого сигнала;
- финальный промышленный интерфейс.

# 21. Ближайшие задачи, которые прямо следуют из этой презентации

## 21.1 Восстановить аналоговую архитектуру текущего стенда

Нужно получить схему от катушек до AD7357 и ответить:

```text
что входит в ADC?
сырая несущая?
демодулированный SIN/COS?
какая амплитуда?
какой common-mode?
какие фильтры?
```

## 21.2 Получить реальные осциллограммы

Нужны одновременно:

```text
возбуждение генераторной катушки
сырой SIN
сырой COS
сигнал после предварительного усилителя
сигнал непосредственно на входе AD7357
```

## 21.3 Определить реальный электрический период нашей шкалы

Не предполагать его заранее.

## 21.4 Проверить квадратуру

Для реальных каналов измерить:

```text
DC offset
амплитуды
фазовый сдвиг
эллиптичность A/B
гармоники
шум
```

## 21.5 Только после этого строить алгоритм положения

Предварительная цепочка:

```text
raw A/B
→ demodulation, если нужна
→ offset correction
→ amplitude normalization
→ quadrature correction
→ filtering
→ atan2/CORDIC
→ phase unwrap
→ period counter
→ linear coordinate
→ calibration correction
```
