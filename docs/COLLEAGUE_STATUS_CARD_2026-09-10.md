# Карточка коллеги: «Работы по ПЛИС»

Дата добавления в документацию: 10.09.2026.

Источник: фотография карточки/отчёта, которую коллега готовил для руководителя перед отпуском. Ниже сохранён смысл и формулировки карточки. Это важный источник по фактическому направлению работ до текущего этапа.

## Работы по ПЛИС

За этот период были выполнены следующие задачи:

1. Продолжается работа по изучению и симуляции абсолютной части энкодера:
   - тестируются первые версии алгоритма для получения позиции из сигналов, которые возвращают датчики в абсолютной части;
   - к расчётам также добавлено положение внутри миллиметра, симулируя инкрементальную часть, чтобы алгоритм возвращал сразу точное положение;
   - добавлен прогон по всей ленте для выявления ошибок конфигурации параметров (ширина ячеек, ширина и шаг датчиков) и алгоритма.

2. В программе для ПЛИС прокинули сигналы от катушек на выход:

```text
катушки → АЦП → ПЛИС → ЦАП → выход
```

Идея: считывать сигнал с катушек с периодом генератора; в теории сигнал должен сразу подходить для ПЛИС. На момент карточки уже столкнулись с шумом и другими проблемами, которые выяснялись.

3. Дорабатывалась программа для отрисовки графиков, передаваемых с ПЛИС на компьютер через UART.

## Планы из карточки

1. Доработать алгоритм в симуляции и выработать ограничения, которые алгоритм накладывает на физические параметры ячеек и датчиков. В частности — определить допустимую максимальную ширину датчиков и минимально необходимое количество датчиков.
2. Продолжать работать над тестовым стендом и проверить корректность программы на ПЛИС.
3. После появления программатора для российской ПЛИС начать работу и изучение российской ПЛИС.

## Что эта карточка подтверждает

### Подтверждено самой карточкой

- рабочая цепочка стенда рассматривалась как `катушки → АЦП → ПЛИС → ЦАП → выход`;
- сигнал планировали считывать синхронно, с периодом генератора;
- проблема шумов уже была известна до текущего этапа;
- UART использовался для передачи данных с ПЛИС на ПК и отрисовки графиков;
- отдельно велась симуляция абсолютной части энкодера и положения внутри миллиметра.

### Не следует считать подтверждённым только по карточке

- точный источник шума;
- точная аналоговая схема между катушками и АЦП;
- точная фаза выборки относительно несущей;
- допустимый уровень шума;
- наличие или отсутствие конкретной фильтрации в старых версиях;
- точная реализация старого арктангенса.

Эти пункты требуют схемы, исходников или измерений на стенде.
