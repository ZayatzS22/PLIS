# Диагностика второго аналогового выхода MAX5853 — 2026-09-10

## Подтвержденный результат стенда

При диагностической прошивке, где в оба входа контроллера ЦАП подан один и тот же канал `adc_out_a[13:4]`, получено:

- голубой аналоговый выход ЦАП показывает изменяющийся сигнал;
- желтый аналоговый выход ЦАП остается практически прямой линией.

Это важный результат: поскольку `data_a` и `data_b` в FPGA получают одно и то же цифровое значение, причина различия между двумя аналоговыми выходами находится после этой точки. Канал B АЦП и `adc_receiver` для этого конкретного симптома не являются первыми подозреваемыми.

## Текущий код

В штатном варианте:

```verilog
.data_a(adc_out_a[13:4]),
.data_b(adc_out_b[13:4]),
```

В диагностическом варианте A/A:

```verilog
.data_a(adc_out_a[13:4]),
.data_b(adc_out_a[13:4]),
```

Контроллер MAX5853 использует одну 10-битную шину `dac_data` и чередует значения для A и B:

```verilog
if (clk_div_cnt == 2'd1) dac_data <= data_a;
if (clk_div_cnt == 2'd3) dac_data <= data_b;
```

## Основная гипотеза

MAX5853 после power-up по умолчанию находится в non-interleaved mode. Для работы существующего проекта требуется включение interleaved mode через бит IDE в control word. В interleaved mode данные обоих каналов передаются через порт A: канал B захватывается по падающему фронту такта, канал A — по следующему возрастающему фронту.

В текущем контроллере при reset на шину устанавливается control word:

```verilog
10'b01_1000_0000
```

Это соответствует:

- PD = 0;
- DACEN = 1;
- IDE = 1;
- REN = 0;
- остальные биты настройки gain/unused = 0.

Затем `dac_ctrl` (CW) переводится из 0 в 1. MAX5853 фиксирует control word по возрастающему фронту CW.

Если CW не доходит до MAX5853, приходит не в нужный момент либо бит IDE на физическом входе DA7 не равен 1 в момент фронта CW, MAX5853 останется в non-interleaved mode. В таком случае канал A может работать, а канал B будет ожидать данные с отдельной шины DB, которую текущий top-level не формирует. Это хорошо согласуется с наблюдаемым симптомом «A работает, B — прямая».

## Что измерять дальше

### 1. Исключить осциллограф/щуп

Поменять щупы CH1/CH2 местами на физических выходах DAC A и DAC B. Если неподвижная линия остается привязана к тому же физическому выходу B, дело не в канале осциллографа или щупе.

### 2. Проверить CW / `control`

По UCF:

```text
control -> FPGA pin G9
```

При активном reset `control` должен быть 0. После отпускания reset примерно через 64 системных такта 27 MHz, то есть около 2.4 мкс, должен появиться переход 0 -> 1.

Для осциллографа удобно использовать Single acquisition и trigger по rising edge `control`, затем нажать/отпустить reset.

### 3. Проверить control word в момент rising edge CW

По текущему UCF:

```text
signal_out[9] -> R11  = PD     -> должен быть 0
signal_out[8] -> T12  = DACEN  -> должен быть 1
signal_out[7] -> Y11  = IDE    -> должен быть 1
signal_out[6] -> C5   = REN    -> должен быть 0
```

Критично подтвердить хотя бы `signal_out[7] = 1` непосредственно перед и после возрастающего фронта CW. Это бит IDE, включающий interleaved mode.

### 4. Проверить такт DAC

Текущий код формирует `dac_clk = clk_div_cnt[1]`, то есть примерно 6.75 MHz при `clk = 27 MHz`.

По UCF:

```text
out_clk_p -> R9
out_clk_n -> R8
```

Так как канал A уже работает, наличие такта вероятно, но для B важен корректный падающий фронт, на котором в interleaved mode захватываются данные канала B.

### 5. Контрольный тест константами

После проверки CW можно временно исключить ADC:

```verilog
.data_a(10'd400),
.data_b(10'd400),
```

В interleaved mode оба аналоговых выхода должны давать одинаковый постоянный уровень. Если A дает уровень, а B остается прямой/нулевой линией другого уровня, проблема точно в конфигурации/захвате/аналоговом тракте DAC B, а не в ADC.

Далее можно проверить разные значения:

```verilog
.data_a(10'd250),
.data_b(10'd750),
```

и убедиться, что физический OUT A соответствует 250, а OUT B — 750.

## Приоритет причин

На текущем этапе проверять в таком порядке:

1. CW действительно имеет фронт 0 -> 1 после reset.
2. IDE (`signal_out[7]`) действительно равен 1 в момент фронта CW.
3. Правильно ли подключена 10-битная шина к порту DA0..DA9 MAX5853.
4. Правильно ли работает такт в interleaved mode, особенно захват B по falling edge.
5. Исправен ли аналоговый выход B и его внешняя обвязка.

`adc_receiver` и второй канал AD7357 пока не менять для этого симптома: A/A уже показывает, что два одинаковых цифровых значения расходятся только на стадии ЦАП/после нее.
