# Bosch Rexroth IMS — презентация 2019 года

Источник: `IMS 2 поколение.pdf`, 35 страниц.

Презентация Bosch Rexroth `Integrated Measuring System - IMS for Ball and Roller Rail Systems`, Matthias Wolf, 14.01.2019.

Этот документ показывает более современное состояние семейства IMS и важен как ориентир того, к чему должна стремиться наша будущая система по архитектуре, точности, надежности и удобству интеграции.

---

# 1. Два варианта IMS

Bosch разделяет семейство на:

```text
IMS-I — Integrated Measuring System, Incremental
IMS-A — Integrated Measuring System, Absolute
```

IMS-I дает инкрементальную информацию положения.

IMS-A имеет абсолютную кодовую структуру и способен выдавать абсолютную координату после включения без обязательного референсного перемещения.

---

# 2. Что Bosch называет IMS

Bosch определяет IMS как высокоточную систему измерения, полностью интегрированную в направляющий рельс.

Основная идея:

```text
линейная направляющая
+
линейный энкодер
→
единый компактный узел
```

За счет полной интеграции отдельная внешняя стеклянная линейка не требуется.

Bosch особо подчеркивает индуктивный принцип измерения и связанную с ним устойчивость к тяжелой промышленной среде.

---

# 3. Компоненты

Система состоит из трех крупных частей.

## 3.1 Каретка

Шариковая или роликовая каретка с адаптером.

Возможны разные:

- типоразмеры;
- классы точности;
- классы предварительного натяга.

## 3.2 Измерительная головка / scanner

Содержит:

- сенсоры;
- электронику;
- кабель;
- разъем.

Головка уже устанавливается на каретку.

## 3.3 Рельс

Содержит:

- инкрементальную шкалу;
- для IMS-I — реферные метки;
- для IMS-A — абсолютную кодовую дорожку;
- защитную ленту/заглушки.

---

# 4. Конструкция измерительного узла

На схеме Bosch выделены:

```text
1  рельс со шкалой и reference/absolute code
2  торцевое уплотнение
3  опорная пластина
4  scanner
5  адаптер
6  каретка
7  кабель и разъем
8  reference marks или absolute code band
9  incremental scale pitch
10 защитная лента шкалы
11 датчик reference/absolute code
12 основной измерительный датчик
13 evaluation electronics
```

Это особенно важно: Bosch физически разделяет два канала получения координатной информации:

```text
основной измерительный сенсор
+
датчик reference/absolute code
```

То есть локальное высокоточное положение и глобальная идентификация позиции — разные задачи.

# 5. Структура рельса

На слайде `Design – IMS rail construction` указано:

```text
incremental scale pitch = 1000 µm
```

Рядом показаны:

- single reference mark для IMS-I;
- absolute code band для IMS-A.

Это подтверждает, что физическая базовая шкала Bosch имеет миллиметровый шаг, тогда как электрический выход IMS-I может иметь намного меньший период.

---

# 6. Индуктивный принцип и эксплуатационная устойчивость

Bosch прямо утверждает, что индуктивный принцип обеспечивает бесконтактное измерение положения.

Заявленные свойства:

- отсутствие износа измерительной функции;
- отсутствие регулярного обслуживания измерительной части;
- нечувствительность к загрязнениям;
- устойчивость к вибрациям;
- отсутствие магнитных компонентов;
- высокая промышленная надежность.

В презентации показаны испытания IP67:

- водой и СОЖ Curtis S90;
- пылью;
- дополнительное испытание в барабане с металлической стружкой, 800 км.

Для нашего проекта это задает отдельный класс требований, который должен рассматриваться после отработки алгоритма в лаборатории.

---

# 7. Зачем IMS нужна в системе управления движением

Bosch показывает различие между косвенным и прямым измерением положения.

## Semi-closed loop

Положение оценивается по датчику двигателя. Между двигателем и фактической кареткой остаются механические звенья, которые могут вносить ошибки.

## Closed loop

Положение измеряется непосредственно на линейной оси.

Интегрированный датчик позволяет использовать фактическую координату каретки в контуре регулирования.

Для нашего проекта это означает, что конечный датчик должен давать не просто красивый график положения, а значение с достаточной:

- задержкой;
- частотой обновления;
- устойчивостью;
- повторяемостью

для работы в замкнутом контуре привода.

---

# 8. Преимущества абсолютного варианта IMS-A

Bosch указывает для абсолютной системы:

- абсолютная координата доступна сразу после включения;
- не требуется батарея;
- не требуется референсное движение при запуске.

Практический смысл — сокращение времени запуска станка и уменьшение риска столкновения инструмента или детали при процедуре референсирования.

Для нашего проекта вопрос `incremental или absolute` должен быть зафиксирован как один из основных системных требований.

---

# 9. Точностные характеристики презентации 2019

Bosch приводит:

```text
точность шкалы: до ±3 мкм/м
повторяемость: ±0,25 мкм
точность интерполяции: ±0,75 мкм
разрешение значения положения: до 0,025 мкм
```

Очень важно не путать:

```text
resolution != accuracy
```

Разрешение 0,025 мкм означает очень мелкий цифровой шаг выдаваемого значения, но фактическая системная ошибка определяется шкалой, интерполяцией, механикой, температурой и калибровкой.

Для нашей системы необходимо отдельно задавать и измерять:

- разрешение;
- повторяемость;
- локальную интерполяционную ошибку;
- абсолютную точность по длине.

# 10. Интерфейсы IMS-I

В презентации указаны:

```text
M17 / 17 pin
1 Vpp / 40 µm
TTL 1 µm
TTL 5 µm
TTL 10 µm
IP67
```

То есть IMS-I может выдавать как аналоговые квадратурные сигналы, так и уже интерполированные цифровые импульсы.

---

# 11. Интерфейсы IMS-A

На слайде IMS-A показаны различные промышленные варианты разъемов, включая M17 и M23, с совместимостью с приводными экосистемами Bosch/Siemens/FANUC.

В самой презентации детальный цифровой протокол не раскрыт, поэтому его нельзя восстанавливать по этому PDF догадками.

# 12. Механические варианты

Для шариковых направляющих указаны типоразмеры:

```text
20 / 25 / 30 / 35 / 45
```

Для роликовых:

```text
35 / 45 / 55 / 65
```

Указываются разные классы предварительного натяга, точности и сторона установки scanner.

Для шариковых систем длина до 4500 мм, для роликовых — до 4000 мм.

Точностные классы в презентации приведены как ±3 и ±5 мкм/м при 20 °C.

# 14. Промышленные применения

Презентация показывает применение IMS в:

- 2D/3D лазерных станках;
- пятиосевых обрабатывающих центрах;
- деревообрабатывающих машинах;
- станках для обработки колесных пар;
- производстве батарей и дисплеев;
- плоттерах;
- PET-инжекционных системах;
- сварочных установках;
- демонстрационных линейных осях.

Системы используются как с линейными двигателями, так и с шарико-винтовыми приводами.

Это подтверждает, что измерительная система должна быть самостоятельной относительно типа привода.

---

# 15. TCO и эксплуатационная цель

Bosch отдельно рассматривает Total Cost of Ownership.

Ключевые преимущества интеграции:

- минимальное время монтажа;
- отсутствие отдельной юстировки измерительной системы;
- отсутствие внешней стеклянной линейки;
- экономия монтажного пространства;
- защита IP67;
- уменьшение простоев и обслуживания.

Приведен пример шлифовальных станков, где замена загрязняемых стеклянных линеек на IMS дала заявленную экономию около 10 тыс. евро на машину за счет уменьшения простоев и обслуживания.

# 18. Главное отличие Bosch от нашего текущего стенда

Bosch показывает уже законченный scanner, в котором датчики, обработка, калибровка и интерфейсы находятся в одной головке.

Наш SP605-стенд сейчас наоборот специально разделяет функции и выводит сырые данные наружу. Это нормальный этап НИОКР.

Текущая задача стенда:

```text
понять физику сигнала
→ получить корректные raw A/B
→ разработать математику
→ проверить калибровку
→ после этого определить, что переносить в конечную электронику датчика
```
