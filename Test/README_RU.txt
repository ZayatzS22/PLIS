SP605 — TEST / офис / без АЦП
================================

Контрольная версия собрана 20.08.2026 по четырём присланным фотографиям sin_gen.v
и сверена с сохранённой тестовой веткой UART_14bit_test_FFFF_SP605.

Логика теста:
- физический АЦП не используется;
- канал A: test_value от 0 до 16383;
- канал B: 16383 - test_value;
- для каждого кадра A + B = 16383;
- маркер блока: FF FF;
- между маркерами 128 кадров;
- кадр: A_low, A_high, B_low, B_high;
- UART: 115200, 8N1, clk 27 МГц.

reference_screenshots/

сверены с ранее сохранённой версией этого же тестового автомата.
