# PLIS — датчики линейных направляющих / Xilinx SP605

Репозиторий исследовательского проекта по разработке собственной высокоточной системы измерения положения каретки для линейных направляющих предприятия.

## Основная документация

- [`PROJECT_DOCUMENTATION.md`](PROJECT_DOCUMENTATION.md) — **главный технический справочник проекта**: архитектура, документация, MAIN/TEST, AD7357, MAX5853, UART, UCF, текущие задачи, риски, что уже есть и чего не хватает.
- [`PROJECT_NOTES.md`](PROJECT_NOTES.md) — рабочий журнал и история решений.
- [`IMS_RESEARCH.md`](IMS_RESEARCH.md) — подробное исследование Bosch IMS и будущего алгоритма определения положения.

## Код

- [`Main/`](Main/) — основной проект для реального стенда: SP605 + плата расширения + AD7357 + MAX5853 + механический стенд.
- [`Test/`](Test/) — офисный автономный тест без физического АЦП, предназначенный для проверки UART и формата данных.

## Документация

- [`SP605doc/`](SP605doc/) — офлайн-документация по Xilinx SP605 / Spartan-6 XC6SLX45T-3FGG484, включая UG526, UG385, UCF и навигатор пинов.
- `AD7357 (АЦП).pdf` — datasheet двухканального 14-битного АЦП основного стенда.
- `IMS 2 поколение.pptx` — материал Bosch по IMS второго поколения.
- `58da99240997b5810a805d76753b7128.pdf` — дополнительный материал Bosch IMS.
- `Презентация IMS.doc` — внутренний материал по раннему изучению IMS и первоначальным наработкам на нашем стенде.

## Текущий этап

В MAIN подготовлена экспериментальная передача результатов AD7357 на MAX5853 одновременно с сохранением UART-передачи. Перед дальнейшим развитием алгоритма необходимо на реальном стенде подтвердить точное разрядное выравнивание 14-битного результата AD7357 внутри `adc_out_a/b`, затем записать качественные сырые данные A/B при движении каретки.

Все новые существенные технические выводы необходимо фиксировать в Markdown вместе с датой, версией кода/commit и результатом проверки на стенде.
